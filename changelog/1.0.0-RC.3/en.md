Third release candidate of Vixeeny 1.0. Please report anything that goes wrong: Settings → About → Report a problem.

## Captures

- New shortcut: Copy the text of a region (CTRL + ALT + PRINT SCREEN). Pick a region on the frozen screen; its text goes to the clipboard, without the editor.
- New shortcut: Pin a region (CTRL + SHIFT + F8). Pick a region on the frozen screen; it stays above the other windows, without the editor.
- In the region picker, Enter copies the region.

## Recording

- New shortcut: Discard the recording (CTRL + SHIFT + F10). It stops the recording and deletes its files.
- Capture the last region again, Record a region and Record a window now have default shortcuts (CTRL + SHIFT + PRINT SCREEN, CTRL + SHIFT + F9, CTRL + ALT + F9). Existing settings get them when the keys are free.

## Install and updates

- When Vixeeny is already installed, the installer offers to update, repair, downgrade or uninstall it.
- The uninstaller asks whether to keep the settings, and otherwise leaves nothing behind.
- Updates remove the files the new version no longer uses.
- Update notes are in English and French, and appear in the app after an update.
- Updates are checked when the computer wakes up or the network comes back, instead of on a timer.
- Windows' installed apps show the right name and version, also after an update made from the app.
- Start with Windows follows the program when its folder changes.
- Task Manager names Xantoom as the publisher.
- The windows are sharp on every screen, whatever its scaling.

## Fixes

- Vixeeny follows Windows' light or dark mode and accent colour as soon as they change.
- The Mica background only shows on the window in front.
- Saving into a folder where every name seems taken (such as some network shares) no longer hangs.
